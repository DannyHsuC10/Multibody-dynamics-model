# MultibodyGeometryLab 四輪多體幾何工作台

工作台依車輛參數或硬點座標建立四輪雙 A 臂的靜態幾何及固定桿長。可指定行程與轉向來求運動學，也可加入直推避震器、輪端質量與輪胎接地力，模擬路面擾動下的車身與四輪響應。

## 啟動

需要 Python 3.10 以上、Tkinter 和 NumPy。整個 `MultibodyGeometryLab` 資料夾可單獨移動或複製，靜態幾何、參數驗證與預設專案都包含在其中。在 Windows 雙擊 `Start-MultibodyGeometryLab.bat`，或從 `MultibodyGeometryLab` 的上一層執行以下指令。

一般啟動會載入 `new/suspension_geometry.json` 的內建副本。可用 `--project` 指定其他專案。

```powershell
python -m pip install -r MultibodyGeometryLab/requirements.txt
python -m MultibodyGeometryLab
python -m MultibodyGeometryLab --project MultibodyGeometryLab/projects/Example.json
```

## 匯入 `new/` 懸吊資料

1. 按「開啟 JSON」選擇 `new/suspension_geometry.json`，載入車輛與懸吊設定。有提供齒條及拉桿硬點時，會用這些座標初始化轉向接點。
2. 按「匯入硬點 CSV」選擇 `new/hardpoints-edited.csv`，套用四輪 A 臂硬點、輪心、轉向和推桿搖臂座標。也可選擇 `new/suspension_static_points.csv`，套用其 A 臂硬點與輪心。CSV 使用 `name,x_m,y_m,z_m` 欄位，座標以公尺表示。地面參考點與 CSV 的 CG 不參與匯入，重心使用 JSON 的車輛設定。
3. CSV 的 `jacobian_project.deformable_members` 指定變形元件的端點與安裝輪位。其餘桿件匯入時為剛性桿。可在「機構元件」選取可編輯的桿件，將類型切換成 `deformable_members`。
4. 在 `deformable_members` 頁選擇元件。彈簧剛性（N/m）與阻尼（N·s/m）可分別勾選。選擇「液壓缸」時，可輸入固定軸力（N）或設定 A、B 油口的管路。輪胎垂直剛性與阻尼也在同一頁設定。
5. 在「輸入」選擇「路面擾動」或「重心 Heave」。結果表與「2D 訊號圖 → 彈簧阻尼」可查看各元件的伸縮與軸力。專案 JSON 會保存桿件分類與力學設定。

推桿與搖臂以無質量剛體建模，推桿的固定長度用來定位搖臂。若把可編輯的桿件切換為變形元件後增加了輪端自由度，專案仍可儲存，模擬須先補足約束。靜態彈簧預載依輪荷配算；輪位缺乏可提供靜態支撐的元件時，狀態列會列出輪位。僅含靜態硬點的 CSV 可先用於幾何檢查。「車身接點力」的搖臂項為等效反力。

```powershell
python -m MultibodyGeometryLab --project new/suspension_geometry.json --hardpoints new/hardpoints-edited.csv
```

## 編輯快捷鍵

- **Ctrl+Z** 復原上一個編輯，**Ctrl+Y** 重做。涵蓋目前專案的表單、硬點、機構及變形／液壓元件。
- 開啟 JSON 或匯入 CSV 會開始新的編輯記錄。儲存後仍可復原。

## 編輯與計算

1. 在「車輛」設定整車尺寸、輪胎、質量與轉動慣量。懸吊與轉向幾何在「硬點」編輯，也可用「匯入硬點 CSV」載入測量座標。
2. 在「硬點」雙擊任一列，以 mm 編輯上、下 A 臂接點、輪心（WC）、拉桿內側（RACK）或外側（TOE）。編輯 A 臂或輪心會啟用硬點模式，並鏡射到同軸另一側。拉桿接點相對輪心的偏移會鏡射，移動輪心時同側拉桿接點會隨之移動。可按「由專案參數重建 A 臂硬點」更新 A 臂座標。按「解算靜態」更新零位、四輪座標與桿長。
3. 在右側「靜態全車」點選硬點標記，再切到「硬點」頁，表格會捲到並選取對應的輪位和點名。3D 視圖可拖曳旋轉、用滾輪縮放，也可切換前視、側視與上視。重疊的點可在同一位置重複點選切換。
4. 「儲存 JSON」保存目前表單值，「另存 JSON」建立另一個設計版本。「開啟 JSON」可載入本工具的專案，或匯入 Suspension Geometry、Suspension Kinematics 與 Suspension Statics 輸出的共用硬點。儲存的 JSON 也可將共用硬點帶到這三個工具。匯入外部懸吊專案後，首次儲存需選擇本工具的檔案路徑。

若行程超出可達範圍或 Jacobian 接近奇異，介面會指出無法解算的輪位並顯示靜態幾何。可先減少輪心行程或齒條位移，並從「固定桿長／誤差」查看收斂結果。

## 模擬結果播放

從「輸入」執行動力模擬後，可使用 3D 視窗下方的播放、暫停、停止與時間軸。拖曳時間軸會暫停，方便檢查該格的輪心、轉向角及桿長。

## 桿件角運動與 2D 訊號圖

在 3D 視窗下方選擇結果輪位，再切到「桿件角運動」。每輪 11 條桿件約束都會顯示從端點 A 指向 B 的車身座標方位角、仰角、距靜態方向的夾角，以及三軸角速度與角加速度。方位角從 +X 朝 +Y，仰角向上為正。桿軸若與 Z 軸平行，方位角欄會顯示「—」。

上下 A 臂的角速度及角加速度沿已知鉸鏈軸。可在「A 臂鉸鏈」查看相對靜態的有號轉角及其導數，正向沿車身前接點指向後接點。羊角約束邊使用羊角剛體的角運動。轉向拉桿只有兩端接點，因此角速度及角加速度描述桿軸方向的變化，繞桿長軸的自旋需要額外的姿態約束才能求解。

完成動力模擬後，按 3D 視窗上方的「2D 訊號圖」開啟曲線視窗，再選輪位、節點、桿件或 A 臂鉸鏈與訊號。節點可選 XYZ 位置、速度及加速度，桿件可選方向角、角速度或角加速度。曲線橫軸是秒，數值採車身座標。方位角曲線連續展開，跨過 ±180° 時保持平滑。播放時游標與 3D 同步。點選或拖曳曲線區可暫停並查看最接近該時間的求解姿態。

## 推桿與輪端動力學

1. 到「推桿」選擇 FL、FR、RL 或 RR。以靜態車身座標輸入 `PUSH_OUT` 與 `PUSH_IN` 的 X、Y、Z（mm）。輪端可以跟隨下 A 臂、上 A 臂或 upright，每個輪位獨立設定。
2. 車體側選「直連車體」時，`PUSH_IN` 固定於車體，推桿可伸縮並自動加入 `deformable_members`。在該頁選擇「輪位 · 直連推桿」可設定剛性、阻尼或液壓缸軸力。
3. 車體側選「連接搖臂」時，另外輸入 `ROCKER_A` 與 `ROCKER_B` 定義固定於車體的旋轉軸。推桿的長度取自靜態位置，作動時保持固定。`PUSH_IN` 隨搖臂旋轉。
4. 在 `deformable_members` 按「新增座標元件」或「編輯端點」。可選車體、各輪的上／下 A 臂、upright、已定義的搖臂，或其他變形元件的 A／B 端，支援跨輪配對。直接安裝在車體或懸吊部件時，以靜態 XYZ（mm）指定接點。選擇其他元件的 A／B 端時，兩支元件共用該接點，位置與速度由被參照的端點決定。直連推桿的端點在「推桿」頁編輯。
5. 在「車輛」填寫輪端質量（kg），在 `deformable_members` 設定四輪共用的輪胎垂直剛性（N/m）與阻尼（N·s/m）。在「輸入 → 路面擾動」選擇單輪或四輪，再設定擾動高度與時間。

避震器軸力沿當下兩端的連線作用。正的長度變化代表伸長，正的軸力推開兩端。可在「避震器」或「2D 訊號圖 → 彈簧阻尼」查看變形元件的行程與受力。彈簧預載依靜態輪荷配算，輪胎離地時正向力為零。

新設定以各輪位的 `pushrods` 存入專案 JSON（公尺）。舊專案可選擇「沿用專案」。硬點 CSV 的 `PUSH_IN`、輪端硬點及有提供的搖臂軸座標會載入「推桿」。

## 雙作用液壓缸與共壓管路

### 液壓設計工作台

在視窗上方切到「液壓設計」，即可使用 `Hydraulic_model` 的完整工作台。可在畫布上新增和拖曳液壓缸、避震器，用圓形油口接油管，用方形機械接點連接活塞桿、避震器與車體固定點。固定點在車體座標中的位移與速度為零。各缸可設定外力或指定位移，各避震器可設定剛性與阻尼。

按「求解靜力」查看油壓、位移與所需外力，或在「瞬態模擬」查看時間曲線並選擇是否開啟油路一階延遲。可用「載入三缸範例」查看完整接法。切回「多體幾何」再返回時，畫布與結果會保留到視窗關閉。此頁求解畫布上的獨立回路，車輛懸吊回路仍使用其專案內的液壓管路設定。

「開啟 JSON」會把已有缸徑、桿徑及 A／B 油口設定的液壓缸帶入畫布。選取匯入的缸時，「元件設定」會列出 A、B 機械端各自連到的車輛元件。此欄用於查閱專案接法，畫布上的活塞桿負載可另行設定。「專案油路」列出原管路名稱、初始表壓、順應性及接管數。設計頁的求解使用這些參數及線性順應性，瞬態油壓曲線顯示相對初始值的變化。

### 車輛懸吊回路

1. 在 `deformable_members → 液壓管路` 建立管路，設定靜態長度下的初始表壓（MPa）及管路總容積順應性（cm³/MPa）。
2. 選取液壓缸，按「設定 A／B 油口」，輸入缸徑和桿徑（mm）。A 為無桿腔，B 為有桿腔。兩個油口可分別選不同管路。未連接的油口視為零表壓。
3. 要分岔時，讓各支缸的油口選擇同一條管路。每條管路可連接多個油口，使用同一表壓。機械 A、B 端是安裝點，油口是油腔連接，兩者各自設定。

模擬以各缸行程造成的總油腔容積變化與設定順應性計算共用壓力，再以兩腔有效面積計算軸力。壓力最低為零表壓。此模型採同管路瞬時等壓，省略流阻、閥件與壓力傳播延遲。已儲存的固定軸力液壓缸仍可使用原模式。

## 編輯機構元件

單輪局部圖可拖曳旋轉，點一下線條即可選取元件。有安裝搖臂的輪位會標出搖臂軸 `ROCKER_A`、`ROCKER_B` 及推桿內外端。避震器設定可在 `deformable_members` 頁查看。

在左側「機構元件」選擇輪位，點圖上的線條或清單，將元件分類為「剛性桿」或 `deformable_members`。可按「全車設為剛性」從全剛性線條開始，再把選定的元件改成彈簧阻尼。也可以選兩個既有接點新增連線，或移除選取的連線。Push Rod 保留 DAMPER–UBJ 連線，可切換類型。

剛性桿以靜態幾何的長度加入約束。彈簧阻尼使用當下長度與速率計算沿桿軸的力，係數在 `deformable_members` 頁編輯。按「套用機構」後，再進行路面模擬或播放動畫。「2D 訊號圖 → 彈簧阻尼」可按元件看桿長、伸長、速度與軸向力。修改後的元件清單隨 JSON 存入 `dynamics.elements`。

目前每輪支援以輪心垂直行程表示的單一自由度，以及固定桿把相對輪端鎖定的配置。全剛性時，路面模擬仍會計算輪胎變形和車身姿態。若把原有剛性桿改成彈簧後，產生額外的獨立運動或輪心行程無法獨立控制，程式會指出輪位，可檢查是否該補上其他剛性連線。這裡的剛性桿是兩接點間的固定距離約束。

## 車身轉動慣量

在「車輛 → 車身轉動慣量」輸入簧上車身繞重心的 Ixx、Iyy、Izz，分別對應 X 側傾、Y 俯仰、Z 偏航，單位都是 kg·m²。預設 55、95、125 kg·m² 是可修改的起始值，假設車身座標軸為慣量主軸。舊專案會帶入這組值，存檔時寫入 `dynamics.chassis_inertia`。

「輸入 → 路面擾動」聯立車身三軸平移與三軸轉動，以及各輪相對車身的行程。車身繞簧上重心轉動，簧上重心位置由整車重心與四輪輪端質量配算。轉動方程使用隨姿態轉換的慣量張量，並計入角速度產生的陀螺項。輪端仍以集中質量表示，地面接觸力沿垂直方向。3D 可直接看側傾、俯仰與偏航，「2D 訊號圖 → 車身」可追蹤角度、角速度與角加速度。

## 重心受力與車身 Heave

在「輸入 → 重心 Heave」輸入向下力、施力上升時間與模擬時間，再按「模擬重心 Heave」。輸入正值向下，負值向上。預設 600 N 在 0.25 秒內平滑增加到目標值，此後維持到模擬結束。這個工況的地面固定在 Z = 0，車身只沿 Z 軸平移，求解器同時積分車身和四輪運動，輪胎接地力由相對地面的輪心高度和速度計算。車輛總質量扣除四輪輪端質量即為車身質量；兩者皆受「車輛」頁設定的重力。計算由含輪胎靜態壓縮與避震器預壓的零位開始。設定會隨專案寫入 `dynamics.heave`。

在「2D 訊號圖 → 車身」可看重心 Z 位移、速度、加速度及外力，地面座標 +Z 向上。比較「避震器 → 相對靜態伸長」時，負值表示避震器縮短。

可用 600 N、0.05 秒上升時間和 3 秒模擬時間觀察零阻尼震盪。在 `deformable_members` 頁關閉避震器阻尼，並將輪胎垂直阻尼設為 0。在輪胎維持接地且外力穩定後，重心應繞著受力後的平衡高度持續震盪。若輪胎垂直阻尼大於零，它仍會耗散震盪能量。

## 重心側向力

在「輸入 → 重心側向力」設定 Fy、施力上升時間與模擬時間，再按「模擬重心側向力」。正值向左（地面 +Y），負值向右。外力作用於簧上重心，平滑升至目標值後維持。接地輪胎先依正向輪荷分擔側向反力，再依前後力臂調整分配，使反力合計平衡 Fy，並提供維持車頭方向所需的 Mz。離地輪的側向反力為零。模型以理想抓地條件估算側傾及輪荷轉移，未計入輪胎側偏與摩擦極限。

在「2D 訊號圖 → 車身」可看重心外力 Fy 與側傾角，在「避震器」結果表可看各輪正向力。此工況設定隨專案存入 `dynamics.lateral`。

## 馬達行駛與輪胎力

在「輸入 → 馬達行駛」設定每顆馬達的扭矩指令、前輪平均轉角、初始車速與模擬時間。四輪各有一顆輪內馬達，共用扭矩指令、傳動效率及預設 11.2:1 的減速比。各馬達的扭矩在前 0.25 秒平滑增加，並依各自對應的輪速及 `Motor/motor_speed_vs_torque.csv` 曲線限制。CSV 取自 `Motor/excel/motor_speed_vs_torque.xlsx` 的擬合結果。正轉角向左，初始車速可設為 0。程式以靜態前輪平均轉角標定齒條位置，模擬中固定齒條，懸吊行程仍會影響各輪方向。

此模式需要同一儲存庫內的 `Motor` 和 `Pacejka_tire_model`。平坦地面上，各輪的瞬時輪荷、輪速及輪心速度用來計算 Hoosier W8 的穩態聯合滑移力。低速滑移採平滑化處理，正向輪荷仍由垂向輪胎模型計算。模型未另外施加 Pacejka 輪胎力矩、空氣阻力或輪胎鬆弛長度。視窗以車身所在位置跟隨顯示姿態，右下角小圖顯示地面座標的行駛軌跡。

「車輛時序圖」並排顯示 Roll／Pitch、四輪正向輪荷、重心平面車速及地面座標的 XYZ 加速度。點擊或拖曳圖表會跳到相同的播放時間，時間軸下方也會更新這些讀值。行駛時主視圖會跟隨車輛，地面格線依車輛位移移動，綠線標出截至目前時間的地面行駛軌跡。

「2D 訊號圖 → 車身」可查看車速與四顆馬達的平均扭矩、平均轉速。「Pacejka 輪胎」可依輪位查看馬達扭矩、馬達轉速、輪上驅動扭矩、Fx、Fy、Fz、滑移率、側偏角與輪速。將「輪位」設為「四輪比較」，可在同一張圖疊加 FL、FR、RL、RR 的所選訊號。播放或拖曳圖表時，游標會顯示同一時間的四輪數值。有輪荷資料的其他工況也可比較 Fz。設定存入 `dynamics.drive`。

## 座標與 JSON

- 車輛採 X 向前、Y 向左、Z 向上。前軸 X 為 0，後軸 X 為負軸距。輪心上壓為正，齒條向左平移為正。同一車軸的左、右內側接點使用同一個齒條位移。
- 硬點表使用車身 XYZ 座標及 mm。四輪工況的位移、速度和加速度以 mm、mm/s、mm/s² 輸入。角度以度顯示，羊角角速度及角加速度以 rad/s、rad/s² 顯示。
- 專案頂層含有 `format`、`schema_version`、`geometry`、`steering`、`motion`、`animation` 和 `dynamics`。其中 `geometry` 使用 SuspensionGeometryLab 格式，長度以 m 保存。`steering` 的前後軸內外側接點偏移也以 m 保存，`motion`、`animation` 和 `dynamics` 使用各自介面標示的單位。
- 匯入的 `static_camber_deg`、`roll_stiffness_ratio` 與 `kinematics_hardpoints` 會隨專案保留。CSV 匯入的輪心及搖臂避震器分別存於 `wheel_centers` 和 `rocker_dampers`。
- 前、後軸預設的轉向拉桿接點是範例座標，可改成實車量測值。初始輪軸方向沿全車 Y 軸，結果中的轉向角和外傾角以此為零位。

## 求解假設

指定單一工況時車身固定。升降與側傾動畫使用已知的車身運動，在地面座標約束輪心高度。基準配置中，每輪上下 A 臂以球接點到兩個車身硬點的距離定義，羊角由上下球接點、輪心和外側拉桿接點組成剛體，拉桿長度在工況求解時保持靜態值。套用自訂機構後，求解器依目前的固定桿長約束組裝 Jacobian。

位置解從靜態位形逐步追蹤到指定工況。各桿件約束採平方距離形式，除以靜態長度以改善數值尺度。速度與加速度由約束方程的一階與二階時間微分求得，包含移動齒條及桿件相對速度的二階項。每筆結果描述指定位移、速度、加速度對應的瞬時運動。外力、質量慣性、彈簧阻尼力與輪胎接地反力屬於動力學模型。
